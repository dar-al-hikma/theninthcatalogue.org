Zīj

زِيج

Free desktop software from The Ninth Catalogue™

A zīj is a set of astronomical tables with the rules for using them. This one is a study companion for traditional natal astrology: cast a chart, then check, table by table, what the texts say about it.

  • The rules come from Benjamin Dykes’s translations of Sahl b. Bishr and Abū Ma’shar, and every rule a page applies names the sentence it comes from.
  • Where a text leaves something open, the page says so and shows the reading it made. Where the texts settle nothing, the result is reported unresolved, with its reason and the alternatives.
  • It works offline: places come from a bundled atlas, and the planets from the built-in Moshier ephemeris.
  • The judgment of the chart is the astrologer’s.

Free download

Zīj runs on a desktop or laptop computer, not on a phone or tablet.

Zīj is free to download and use. Each download is portable: unzip it and run it. There is no installer, and once it is on your computer it needs no internet. Your saved charts and preferences live in your own data folder and carry over from one version to the next. The links always fetch the current release.

Windows

Windows 10 or 11, 64-bit
Download for Windowszip · about 430 MB

Right-click the zip and choose Extract All, then open Zij in the folder it makes. It will not run from inside the zip.

The first time, Windows may say it has protected your PC from an unrecognised app. Choose More info, then Run anyway.

macOS

Apple silicon: M1 or later
Download for macOSzip · about 175 MB

Open the zip if your browser has not already, move Zij to Applications if you like, and open it.

The first time, macOS will say it cannot verify the developer. On macOS 15 or later, open System Settings › Privacy & Security, scroll down and choose Open Anyway. On earlier versions, Control-click Zij and choose Open.

There is no build for Macs with Intel processors. They can run Zīj from its source, as on Linux.

Linux

From source

There is no packaged download for Linux yet. Zīj runs from its source with Python 3.14, in your browser. One of its parts is compiled as it installs, so you need a C compiler and Python’s development files; on Debian or Ubuntu, build-essential, python3.14-dev and python3.14-venv.

git clone --depth 1 https://github.com/dar-al-hikma/Zij.git
cd Zij
python3.14 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python run_source.py

Open the address it prints. It carries a key made for this run alone, and the app answers only there; Ctrl-C stops it. It serves this computer only, though other accounts on the same computer can reach it while it runs.

Each release lists the SHA-256 of its zips in SHA256SUMS. To check a download, compare its hash with its line there: shasum -a 256 Zij-macos.zip on macOS, or Get-FileHash Zij-windows.zip in PowerShell on Windows, which prints it in capitals.
