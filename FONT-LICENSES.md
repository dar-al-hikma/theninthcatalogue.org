# Embedded fonts

Every page here embeds its typefaces as base64 `woff2` inside the HTML. The faces are subset to
Latin plus Arabic transliteration; Arabic script is left to system fonts.

All three families are licensed under the **SIL Open Font License, Version 1.1**, which permits
embedding in a document. Full text: <https://openfontlicense.org>
